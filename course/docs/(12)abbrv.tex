\ssr{ОБОЗНАЧЕНИЯ И СОКРАЩЕНИЯ}

В представленной расчетно-пояснительной записке используются следующие сокращения и обозначения:
\begin{enumerate}
    \item БД -- база данных;
    \item СУБД -- система управления базами данных;
    \item ER -- Entity Relationship;
    \item API -- Application Programming Interface;
    \item SQL -- Structured Query Language;
    \item ЭВМ -- электронно-вычислительная машина;
    \item B-Tree -- Binary tree.
\end{enumerate}
