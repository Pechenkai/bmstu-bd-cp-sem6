\ssr{ЗАКЛЮЧЕНИЕ}

Цель данной работы была достигнута: разработана база данных для хранения
наборов данных (датасетов), также создано приложения для доступа к ней.
Все поставленные задачи были успешно решены:

\begin{itemize}
\item проведён анализ предметной области и выделены ключевые сущности, а также их взаимосвязи;
\item сформулированы требования к системе, включая поддержку ролевой модели и обеспечение целостности данных;
\item спроектирована и реализованна база данных с ограничениями и триггером;
\item разработаны и реализованы основные компоненты приложения, взаимодействующего с базой данных;
\item проведено исследование влияния различных типов индексов на производительность запросов.

\end{itemize}
