# Курсовая работа по базам данных

Пояснительная записка к курсовой работе по проектированию базы данных для хранения и каталогизации наборов данных (датасетов).

Отчет [PDF](course/docs/report.pdf).

## Цель работы

Спроектировать базу данных для хранения метаданных датасетов и приложение для доступа к ней. Файлы датасетов предполагается хранить во внешнем S3-совместимом объектном хранилище, а связанные структурированные данные — в PostgreSQL.

## Что рассматривается

- анализ существующих платформ: Kaggle, Hugging Face Datasets, UCI Machine Learning Repository и ClearML;
- модель данных для пользователей, категорий, датасетов, версий, метаданных, подписок, отзывов и уведомлений;
- SQL-ограничения, внешние ключи и индексы;
- функция вычисления среднего рейтинга датасета;
- триггер, автоматически создающий начальную версию, подписку владельца и уведомление при создании датасета;
- роли `guest_role`, `registered_role` и `admin_role`;
- сравнение сценариев без индекса, с B-Tree, UNIQUE B-Tree и `CLUSTER` для операций `INSERT`, `SELECT` и `DELETE`.

## Модель данных

| Сущность | Назначение |
| --- | --- |
| `users` | учётные записи, роль пользователя и статус блокировки |
| `categories` | категории датасетов |
| `datasets` | карточки датасетов, владелец и признак публичности |
| `dataset_versions` | версии и путь к файлу каждой версии |
| `metadata` | формат, размер и теги версии |
| `subscriptions` | подписки пользователей на датасеты |
| `reviews` | оценки и комментарии к датасетам |
| `notifications` | уведомления, связанные с датасетами |

Подробные атрибуты и связи приведены в [конструкторской части](course/docs/(4)design_part.tex), а SQL-листинги — в [технологической части](course/docs/(5)tech_part.tex).
